# Publication Checklist — Natural Language Processing (Cambridge University Press)

**Target venue:** *Natural Language Processing* (NLP), Cambridge University Press.
Formerly *Natural Language Engineering* (NLE); renamed and flipped to full Gold Open Access in 2024.
Online ISSN: 2977-0424.

**Fit:** Strong. The journal explicitly invites submissions on multilingual and low-resourced language projects, and bridges computational linguistics with applied NLP. A morphology-aware tokenization study across nine typologically diverse languages sits squarely in scope.

**Submission platform:** ScholarOne — http://mc.manuscriptcentral.com/nlp

---

## Stage 1 — Before writing the draft

- [ ] Confirm article type: **Article** (detailed, rigorous original study). Not Squib, not Position Paper, not Survey.
- [ ] Register ORCID (mandatory for corresponding author).
- [ ] Create ScholarOne account (separate from Cambridge Core login).
- [ ] Confirm licence expectations with CODE University of Applied Sciences / any funder — default will be **CC BY**; CC BY-NC / CC BY-NC-SA available on request. Note this interacts with the IP-patent plan (Germany) — discuss with supervisor before accepting default.
- [ ] Email NLP@cambridge.org to confirm the four unresolved points:
  - [ ] Blinding type (likely single-blind, unconfirmed post-rebrand).
  - [ ] Default CC variant and whether the patent plan conflicts.
  - [ ] Soft word-count target for Articles (legacy NLE norm was 8,000–12,000 words).
  - [ ] Student/capstone APC waiver availability (list price £2,610 / $3,655).
- [ ] Check CODE University of Applied Sciences / institutional read-and-publish agreement with Cambridge (German institutions under DEAL/Projekt typically covered).

---

## Stage 2 — Manuscript structure and content

- [ ] **Title page**: title, author name(s), full mailing addresses, email addresses.
- [ ] **Abstract: ~300 words** (journal's stated length).
- [ ] **Keywords** (standard expectation, check template).
- [ ] **Sections** — no mandated IMRaD but follow academic convention:
  - [ ] Introduction / Research question
  - [ ] Related work (tokenization, morphology, low-resource NLP)
  - [ ] Methodology (the nine grammar engines + pipeline)
  - [ ] Experimental design (the frozen experimental contract)
  - [ ] Results (Phase 1 mini — three languages; forward statement on Phase 3 — nine languages)
  - [ ] Discussion and limitations
  - [ ] Conclusion and future work
  - [ ] References
  - [ ] Appendices (engine specs, raw numbers, config) if needed
- [ ] **Length**: no public cap. Target ~10,000 words for a full Article; confirm via email.
- [ ] **Figures**: captions **and alt-text** (accessibility requirement). Photographs at 300 dpi.
- [ ] **Tables**: designed for 247 × 174 mm printed page, numbered consecutively (Arabic numerals).
- [ ] **Pages**: single spaced, wide margins, numbered consecutively.

---

## Stage 3 — Formatting

- [ ] **LaTeX is mandatory** — no Word option.
- [ ] Use the Cambridge NLP LaTeX template (Overleaf or downloadable "NLP LaTeX Files").
- [ ] **Citation style: Author-Date** (Harvard-like). Example: `(Lee and Devore 1968: 236)`.
- [ ] Three+ authors: use `et al.` after first name.
- [ ] Multiple works same year → `a, b, c` suffixes.
- [ ] **References** alphabetical by surname, single-spaced:
  - Journal: `Author. (Year). Title. Journal, volume, pp. pages.`
  - Book: `Author. (Year). Title. Place: Publisher.`
  - Chapter: `Author. (Year). Chapter title. In Editor (ed.), Book Title. Place: Publisher, pp. range.`

---

## Stage 4 — Ethics, disclosure, and open science

- [ ] **AI use disclosure** (required when generative AI generates text/images or analyses data). Add to acknowledgments / methods / figure captions as applicable. Not required for spell-checking or single-word insertions.
- [ ] Do **not** list AI tools as authors.
- [ ] **Competing interests declaration** for all authors.
- [ ] **Authorship**: everyone meeting disciplinary norms must be listed; no ghosts, no guests.
- [ ] **Prior publication**: NLP does not accept it; preprints are allowed and do not count as prior publication.
- [ ] **Data / code availability**: *encouraged, not mandatory*. Strongly recommended anyway — publish engines (obfuscated per IP policy) and evaluation logs in an appropriate repository and cite from the paper. Respect the src/ non-deployment rule.
- [ ] **Preregistration**: not mentioned; no required step.

---

## Stage 5 — Submission

- [ ] Submit via ScholarOne: http://mc.manuscriptcentral.com/nlp
- [ ] ORCID attached to corresponding author.
- [ ] Cover letter (ScholarOne will prompt — include: article type, fit with scope, novelty, compliance with ethics/AI disclosure).
- [ ] Suggested reviewers (ScholarOne typically asks; prepare 3–5 names from the tokenization / morphological analysis / low-resource NLP communities).
- [ ] Confirm blinding type before anonymizing.
- [ ] Acknowledge reviewer reciprocity expectation — authors agree to peer-review others in their area.
- [ ] Signed licence to publish (requested before publication, after acceptance).

---

## Stage 6 — Post-acceptance

- [ ] Choose CC licence variant at publishing agreement signing.
- [ ] APC payment or institutional agreement routing (£2,610 / $3,655 list).
- [ ] FirstView publication on Cambridge Core typically within weeks of acceptance.

---

## Supervisor draft — minimum bar

Before sharing with the professor, confirm the draft has:

- [ ] 300-word abstract framing nine-language scope, Phase 1 monotonic gradient, Phase 3 plan.
- [ ] Clear research question and hypothesis.
- [ ] Prior work positioning (BPE/SentencePiece, morphological analysers, low-resource NLP).
- [ ] Methods section covering the nine grammar engines at sufficient depth (with one or two decomposition examples).
- [ ] Experimental contract summary — frozen design, tokenization as the only permitted variable.
- [ ] Phase 1 mini results table (EN/AR/TR, 56.9% / 13.9% / 1% gradient).
- [ ] Honest limitations — Phase 1 is three data points, mini-scale data-limited.
- [ ] Forward statement — Phase 3 nine-language mini experiment is next.
- [ ] AI use disclosure drafted.
- [ ] Competing interests statement drafted.
- [ ] References formatted in Author-Date style.
