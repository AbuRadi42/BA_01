BA_01 — Presenter Notes

Morphological Efficiency in Multilingual LMs

Slide 0
Title

One question: does telling a model the grammar of a language before training make it learn better?

Three languages chosen for their grammar type (and I speak them so I won't be making up insights...) — not randomly.

Slide 1
The Question
BPE vs morph

BPE chops by frequency — no grammar. Morph gives root + grammatical role. Same data, different signal.

Why these languages

English — barely inflects. Arabic — root + vowel pattern. Turkish — suffixes stack. Three different morphological types.

Slide 1b
What Tokenisation Looks Like
Left vs right

Left = raw fragments, no meaning. Right = root + grammatical tag per chip.

Arabic — tap Forms

Shows the وزن pattern for each token. That's the layer BPE never provides.

Fewer tokens

Morph side has fewer chips — each one is doing more work.

Slide 1c
Two Pipelines

Everything identical — architecture, data, budget. Only variable: what the model sees as a token.

Morph pipeline adds a grammar engine step + a second embedding stream for the feature bundle.

Slide 1d
The Three Grammar Engines
What a bundle is

One unique combination of features — e.g. {form=II, voice=ACT, person=3, gender=MASC}.

Bundle counts

English 23 — simple inflection. Turkish 63 — suffix chains. Arabic 270 — person × gender × number × tense × voice × form all at once.

Why 270 matters

Same 3-letter root → dozens of surface forms, each a different bundle. Broken plurals, duals, nisba, masdar all add more. Each morph token carries far more information than any BPE fragment.

Slide 2
Mini Experiment — Setup

Small pilot before spending real money — same code, tiny models, small data slice.

Goal: validate the pipeline and get a directional signal across all three languages.

Slide 3
Metric 1 — Perplexity
Plain language

How surprised is the model by text it hasn't seen. Lower = better. Like a reading comprehension score.

Results

Turkish −57%. Arabic −14% (likely understated). English ≈flat — expected.

Slide 3b
Metric 2 — Learning Speed

Dashed line = morph. If it drops below solid early — grammar gave a head start.

Turkish: pronounced. Arabic: visible. English: parallel — consistent with perplexity.

Slide 3c
Metric 3 — Token Compression

Shorthand vs longhand — fewer symbols, each carrying more meaning.

Tokens-per-meaning-unit: lower = more efficient use of the context window.

Slide 3d
Metrics 4 & 5 — Agreement + Downstream
Bundle accuracy

Did the model correctly predict the grammatical tag? High = it generalised the structure, didn't just memorise.

Arabic 270 bundles context

Getting the right bundle out of 270 is a strong signal the model internalised Arabic morphology.

Metric 5 — not measured

Downstream tasks need labelled data + fine-tuning budget we didn't have. Most practically meaningful — first priority in a follow-up.

Slide 4
What the Mini Tells Us

More complex grammar → bigger gain. Exactly what the hypothesis predicted.

English being flat is a control, not a failure — confirms the effect is language-specific.

Slide 5
Full-Scale Setup
Scale jump

2M → 125M parameters. Small slice → 2.5B tokens. GPT-2-small territory.

Vocabulary explosion

Morph tokenizer produced 27M unique tokens — embedding table ~41GB. Capped to top-50k. 1 in 10 words became unknown. Not a fair fight.

Slide 6
English — Learning Curves

Both curves converge at the same rate — grammar hint doesn't help English at full scale either.

Morph curve may sit slightly higher due to 10.68% unknown token rate inflating loss.

Slide 7
English — Full-Scale Results
Lead with the caveat

Morph scores worse on PPL (55.5 vs 39.4) — but 10.68% unknown tokens. Every unknown = guaranteed wrong. Not a fair comparison.

The number that matters

4.91× tokens-per-meaning-unit. Each morph token carries nearly 5× more grammatical info. Holds regardless of PPL.

Bundle accuracy 100%

Perfectly predicted every grammatical tag. Generalised — didn't memorise.

Slide 8
Arabic & Turkish — Deferred
What was built

Corpora, tokenizers, engines, baseline models — all done. Morph preprocessing and training never started.

Mini signal

AR −14%, TR −57% at small scale. If that holds at full scale, the effect dwarfs English. Full experiment ≈ €1,800.

Slide 9
What Actually Happened
Two reboots

Provider wiped the instance mid-run twice. Fixed with checkpointing.

Pool deadlock

Multiprocessing hung at 27/33 chunks. Fixed with maxtasksperchild=1.

Vocab explosion

27M tokens → OOM. Capped to 50k. Training completed.

Credits ran out

AR/TR baselines trained. Morph training never started. Eval never ran.

The point

Every failure was diagnosed and fixed. That's also part of the research.
