Morphological Efficiency
in Multilingual Language Models

Does teaching a model the grammar of its language — before it sees any data — reduce how much it needs to learn?

The Experiment

Six models. Three languages. One question.

🇬🇧 English
en_base Baseline BPE
en_morph Grammar-aware

Derivational + inflectional morphology engine

🇸🇦 Arabic
ar_base Baseline BPE
ar_morph Grammar-aware

Root × template (النحو والصرف) engine

🇹🇷 Turkish
tr_base Baseline BPE
tr_morph Grammar-aware

Suffix-chain (Dilbilgisi) engine

Each pair shares identical architecture (125M params), identical training data (2.5B tokens), and identical training budget. The only difference is whether the model was given grammatical structure before training.

How We Compare Them

Five metrics. Each captures a different dimension of what "learning efficiently" means.

📉 Metric 1
Perplexity

How surprised is the model by unseen text? PPL = exp(mean(−log P(token))). Lower = better probability distribution over the language.

eval_lm.py
🗜️ Metric 2
Tokens per Meaning Unit

How many tokens to express one idea? Morph unit = (root, template) pair. Lower = more meaning packed per token. Critical for Arabic & Turkish where BPE splits one word into 4–6 fragments.

eval_morphology.py
✅ Metric 3
Agreement Accuracy

Does the model produce grammatically agreeing forms? Subject–verb gender/number in Arabic, vowel harmony in Turkish, tense in English. Higher = grammar internalized.

eval_morphology.py
⚡ Metric 4
Learning Efficiency

How many tokens to reach a target perplexity threshold? If the morph model gets there in fewer steps, the grammar prior gave it a head start. This is the core test of the research claim.

eval_lm.py + compute_metrics.py
🎯 Metric 5
Downstream Performance

Frozen model + single linear probe on sentiment & QA tasks. Tests whether internal representations are useful beyond language modeling. FLOPs also logged for compute-efficiency comparison.

eval_downstream.py

All five metrics are computed for all six models under identical conditions. The comparison is always within-language (en_base vs en_morph, ar_base vs ar_morph, tr_base vs tr_morph). Cross-language perplexity comparisons are not made — vocabularies and token distributions differ.

Grammatical Agreement Accuracy

Does the model produce grammatically correct forms?

Tested on subject-verb agreement, case marking, and number agreement. Higher = more grammatically consistent outputs.

Agreement accuracy is only meaningful for morph models — baseline models have no explicit grammatical structure to validate against. Baseline values reflect the model's implicit grammatical consistency.

Learning Efficiency

How many training tokens did each model need to reach a target loss?

If the morph model reaches the threshold earlier, it learned the same thing with less data. That is the core claim of this experiment.
