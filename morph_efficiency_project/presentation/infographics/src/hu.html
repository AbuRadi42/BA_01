Definite vs. Indefinite Split

Every Hungarian verb has two complete paradigms. The suffix alone tells the engine whether the object is definite or indefinite.

DEF
olvas -om
“I read it”
INDEF
olvas -ok
“I read (sth.)”
Same root, same tense, same person — but -om vs -ok encodes object definiteness.
This fusional slot (person + number + definiteness) is Hungarian’s most distinctive feature.

DEF/INDEF Conjugation Decision

The engine must decide which paradigm a verb form belongs to. Some suffixes are unique identifiers; others are ambiguous.

DEFINITE
-om 1SG
-od 2SG
-ja 3SG
-juk 1PL
-játok 2PL
-ják 3PL
Unique: -om, -od, -ja, -juk, -játok, -ják
INDEFINITE
-ok 1SG
-sz / -ol 2SG
-∅ 3SG
-unk 1PL
-tok 2PL
-nak 3PL
Unique: -ok, -sz, -∅, -unk, -tok, -nak

The engine attempts both paradigms and selects the one that yields a valid stem. Most suffix pairs are unambiguous.

Consonant Assimilation Reversal

The instrumental suffix -val/-vel causes the v to assimilate to the stem’s final consonant. The engine must reverse this to recover the stem.

surface házzal “with a house”
detect házzal → doubled consonant zz at suffix boundary
reverse ház + -val → v → z (assimilated)
output root=ház  case=INSTRUMENTAL

Why This Matters for AI

Hungarian’s agglutinative structure makes it a strong candidate for morph-aware tokenization — each suffix boundary is a meaningful split point that BPE misses.

BPE Tokenization

házaimban
ház aim ban

3 tokens. The possessive -m gets merged with the plural marker -i-, destroying both morpheme boundaries.

Morph-Aware Tokenization

házaimban
ház -a- -i- -m -ban

5 tokens — each is a meaningful morpheme. The model sees root + link + PL + POSS + CASE.

~35-45%

Predicted alignment improvement for Hungarian

Hungarian’s agglutinative suffix chains are highly decomposable, similar to Turkish. With 18 cases, 6 possessive forms, and a DEF/INDEF verbal split, BPE consistently misaligns morpheme boundaries. Morph-aware tokenization should yield strong improvements, likely comparable to Turkish’s measured 56.9% gain.
