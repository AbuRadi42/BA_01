How Arabic Builds Words

Arabic uses a root-and-pattern system unlike anything on the isolating–agglutinative spectrum. Three consonant “stars” form a semantic constellation, and different vowel patterns weave between them to produce entirely different words.

Broken Plurals (Non-Concatenative)

Unlike agglutinative languages, Arabic forms plurals by rearranging the vowel pattern around the same root consonants:

كِتَاب

kitaab (book)

→
كُتُب

kutub (books)

قَلَم

qalam (pen)

→
أَقْلَام

aqlaam (pens)

رَجُل

rajul (man)

→
رِجَال

rijaal (men)

No suffix was added. The internal vowel melody changed. This is non-concatenative morphology.

The WHILE Loop: Proclitic Stripping

The engine strips proclitics in a loop. After each match it restarts, trying all candidates again on the shortened stem. This is unique to Arabic.

وبالمدرسة

wbAlmdrsp ("and with the school")

Pass 1 Try compound proclitics (longest-first)
"وبالف" "وبال" → MATCH!
conj=W prep=B def=DEF
Remaining: مدرسة (madrasa) — 4 consonants ≥ 3 ✓
↻ Restart WHILE loop
Pass 2 Try all proclitics again on shortened stem
No more matches on مدرسة
Exit WHILE — proceed to enclitics
Enclitics Check ة (ta marbuta)
Not an enclitic — handled in template matching as FEM marker
Stem = مدرسة → proceed to template matching

Weak Root Resolution

When the consonant skeleton has only 2 consonants, a “weak” letter (و or ي) was lost. The engine tries inserting it at each position and checks disambiguation lexicons.

skeleton q - l (2 consonants — one is missing)
Ajwaf q - w - l insert و between C1-C3 → check _AJWAF_FRAME
or q - y - l insert ي between C1-C3 → check _AJWAF_FRAME
resolve q - w - l ✓ → root قول (say/speak) confirmed by lexicon

Same process applies to Naqis (append), Mithal (prepend), Geminate (double), and Hamzated (normalize ء).
