## 2. Top 10 Failure Patterns

1. **Nominal POSS classifies as `pos=UNKNOWN`**. `_step_a` finds a POSS tag but no CASE, so the default-pos rule (`"NOUN" if case else "VERB" if tense else "UNKNOWN"`) returns UNKNOWN. Words: `evim`, `evlerim`, `annem`, `kitabım`, `gözüm`, `öğrenciyim`.
2. **First-person PAST_DEF parsed as POSS instead of TENSE+PERSON**. `yazdım/yazdın/yazdı/yazdık/yazdınız` lose the `-dı-` and the `-m/-n/-k/-nız` ending wins as POSS_1SG/2SG/1PL/2PL. The pass-1 vs pass-2 arbiter picks pass-2 (nominal) because pass-1 leaves no tense (the personal ending hides it).
3. **Bare 3SG verbal forms over-segment**. `yazıyor`, `yazar`, `yazacak`, `yazmış`: the consonant-mutation step or aorist segmentation eats the final consonant. `yazacak` → `pos=PART` because `-acak` is recognized as VN_FUT participle, not finite FUT.
4. **Voice slot 5 ambiguity**. `yıkandı` analyzed as `case=DAT` (lost), `yazdırdı` loses CAUS, `yazıldım` loses PASS. The shared `-n/-l` suffixes for REFL/PASS clash with case-poss buffers.
5. **Imperative forms misread as nominal**. `gidin`, `gitsin`, `gitsinler` get `case=GEN` (the `-in` IMP_2PL and `-sin` IMP_3SG variants are tagged as CASE). MOOD slot 8 loses to POSS/CASE slot 3/4.
6. **Potential (ABIL) slot 4.5 not recognized**. `gidebilir`/`yapabilir`/`gidemez`/`yapamadı` lose the `modality=ABIL` tag entirely. The `-ebil-` and `-eme-` surface variants carry trailing hyphens in the JSON, so they never match the `endswith` check after `lstrip("-").rstrip("-")` leaves `ebil`/`eme`, but slot order 4.5 is processed after slot 7+ have already eaten the tense, so no stem is left for it.
7. **Attestative `-dır` only sometimes fires**. `gidiyordur` analyzed but root `gid` (final `g` eaten); `biliyordur` works. Consonant-unmutation runs only for CASE tags, not for the EPIST slot.
8. **Derivational suffixes never fire on common -li/-siz/-ci/-le words**. `evli`, `evsiz`, `kitaplık`, `işçi`, `temizle`, `güzelleş`, `yapıcı`, `çalışkan`, `sevgi`. The 3-char min-stem rule plus 2-char min-suffix rule blocks `ev+li`, `iş+çi`, `sev+gi`. Engine prefers spurious CASE/POSS analysis (e.g., `evli` → `case=ACC`, root `evl`).
9. **Vowel-final stems with s-buffer (3SG POSS) misread as ACC**. `kapısı`, `arabası`, `annesi` all get `case=ACC` because `-sı` is read as `-ı` ACC after stripping `s`. The s-buffer rule in `_BUFFER_SLOTS` only marks slot 3 (POSS), but the longest-match scorer still picks the simpler `-ı` ACC reading.
10. **DAT/INS y-buffer eats stem y**. `arabaya` → root `arabay`, `arabayla` → root `arabay`, `kalemle` → `case=INS` but `poss=1SG` spuriously stripped. The `_buffer_ok` penalty isn't strong enough when the non-buffer variant has a one-vowel match.

| B1 | **Critical** | `pos=UNKNOWN` whenever only POSS is present (no CASE, no TENSE). Affects ~30% of nominal forms. | In `analyze`, treat presence of `poss`/`num` tags as NOUN evidence. |
| B2 | **Critical** | 1/2SG/1/2PL PAST_DEF verbs `yazdım`/`yazdı`/`yazdınız` parse as nominal POSS. Pass-2 nominal arbiter outranks pass-1 verbal because pass-1's `-m`/`-k`/`-nız` is consumed before `-dı` is reached. | In `_step_a` clearly-verbal heuristic, also flag PERSON_NUM tags from pass-1; force pass-1 when a PAST_DEF dental cluster `d/t + vowel + person` is present. |
| B3 | **Critical** | Imperative 2PL/3SG/3PL (`gidin`, `gitsin`, `gitsinler`) read as case. MOOD slot 8 evaluated after CASE in current single-pass logic. | Add a pre-pass that, after detecting MOOD suffix in slot 8, blocks slot 4 CASE from competing. |
| B4 | **Critical** | Derivational slot 1 effectively dead: 9/10 derivations fail. `kitaplık` returns `deriv: ABSTRACT_NOUN` but `pos=UNKNOWN`. `evli`/`işçi`/`sevgi` blocked by min-stem=3. | Lower min-stem in `_step_b` to 2 for high-frequency single-char roots, and surface DERIV pos to `analyze`'s pos-default rule. |
| B5 | **Critical** | Potential `-ebil-` and inability `-eme-` (slot 4.5) never recognized. The JSON surface variants `-ebil-` have a trailing hyphen that strips to bare `ebil`, but slot order 4.5 sits below TENSE (7) in the descending sort, so TENSE has already consumed everything. | Reorder slot 4.5 to fire before TENSE; OR add a pre-pass for ABIL/ABIL_NEG before `_step_a` loop. |
| B6 | **High** | Voice slot (REFL `-n`, PASS `-l`) collides with case/poss. `yıkandı` analyzed as DAT, `yazdırdı` loses CAUS, `yazıldım` loses PASS. | Require voice slot to attach to verbal stems by checking subsequent TENSE marker presence before stripping. |
| B7 | **High** | s-buffer POSS_3SG (`kapısı`, `arabası`, `annesi`) read as ACC, dropping `poss=3SG` and case-marking absent stem. | Increase buffer-variant weight for `-sı/-si/-su/-sü` over `-ı/-i/-u/-ü` when stem ends in vowel. |
| B8 | **High** | y-buffer DAT/INS strips only the inflection vowel and keeps the buffer `y` in the stem: `arabaya` → `arabay`, `kediye` → `kediy`. | When `_is_buffer_variant` triggers and is selected, also strip the buffer consonant from `remaining`. |

| B11 | **Medium** | Negation `-me-/-ma-` lost for 1SG and PAST_NARR: `gitmedim` → POSS_1SG, `yazmamış` → mixed garbage tags. | Add a NEG pre-pass to greedily strip `-me-/-ma-` before TENSE detection. |
| B12 | **Medium** | Attestative `-dır` consumes final root consonant: `gidiyordur` → root `gid` (loses `t`); `bilgisayar` (loan) misread as PRES_AORIST. | Whitelist `-dur/-dır/-tur/-tır` only after a finite TENSE marker. |
| B13 | **Medium** | Consonant unmutation skipped for POSS without CASE: `kitabım` keeps stem `kitab` instead of `kitap`. | Extend unmutation trigger from CASE-only to also fire on POSS tags. |

## 4. Categories With High Pass Rates

- **EC (edge cases) 100%** — no crashes on single-letter, all-caps, hyphenated, or numeric inputs.
- **SL (slot ordering) 100%** — the validator passes even where decompositions are wrong, suggesting validator is too lax; an UNKNOWN pos sidesteps the NOMINAL_ORDER check.
- **IR (irregular verbs) 75%** — `yedi/dedi/etti/oldu` and most progressive irregulars work; only stem-vowel-collapse cases (`oku+iyor → okuyor`, `ye+iyor → yiyor`) fail.
- **V1 TENSE x PERSON 67%** — 3PL and 2PL paradigms mostly clean; 1SG/2SG/1PL/3SG of PAST_DEF and FUT degraded.
- **N2 vowel-harmony 62%** — single-suffix harmony recognition is solid; failures concentrate where buffer consonants stay glued to the stem.
- **N1 nominal Cartesian 59%** — back-vowel + consonant stems with POSS-only inflection are most affected by the UNKNOWN-pos bug (B1).

## Notes for Manuscript

The "concatenative, regular slot order" framing for Turkish hides three structural fragilities the suite exposes:

- The two-pass arbiter trades off well only when both nominal and verbal markers are present; PAST_DEF + 1SG produces a perfect ambiguity with POSS_1SG.
- The buffer-consonant penalty (`-2` in the sort key) is insufficient when the non-buffer variant is much shorter; the surface-greedy scorer needs morphotactic context, not just length.
- Derivational slot 1 with min-stem=3 systematically excludes the most common single-syllable stem derivations (`ev+li`, `iş+çi`, `sev+gi`), which are exactly the cases a morphology-aware tokenizer needs to win against BPE.

These are testing observations only. No engine code was modified.
